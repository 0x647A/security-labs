# API Testing

Apprentice-level labs from [PortSwigger Web Security Academy](https://portswigger.net/web-security/api-testing).

These labs cover finding and exploiting API endpoints - for example, discovering hidden endpoints through exposed documentation and abusing ones that enforce no authentication.

---

## Labs

| Lab | Vulnerability Type |
|---|---|
| [Exploiting an API endpoint using documentation](Exploiting%20an%20API%20endpoint%20using%20documentation/README.md) | Excessive documentation exposure + missing access control - unauthenticated `DELETE` endpoint discovered via API docs |
