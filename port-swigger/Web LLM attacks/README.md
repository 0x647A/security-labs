# Web LLM Attacks

Write-ups for the **Web Security Academy** "Web LLM attacks" learning path, covering vulnerabilities that arise when applications integrate large language models with internal APIs, data sources, and user-facing chat interfaces.

## Labs

| Lab | Level | Summary |
| --- | --- | --- |
| [Exploiting LLM APIs with excessive agency](Exploiting%20LLM%20APIs%20with%20excessive%20agency/README.md) | Apprentice | An AI support assistant is granted an unrestricted `debug_sql` tool, allowing arbitrary SQL (including a destructive `DELETE`) to be executed through chat prompts. |

Each lab folder contains a standalone `README.md` with a vulnerability overview, step-by-step exploitation walkthrough, root-cause analysis, and remediation guidance.
